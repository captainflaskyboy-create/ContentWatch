# ContentWatch icon

- Artwork: `contentwatch.png`, created using the built-in image generation tool with the user's Stream Avatar Studio icon as a style reference. The original reference image and its filesystem path are not included in this repository.
- Windows asset: `contentwatch.ico`, containing PNG representations at 16, 20, 24, 32, 48, 64, 128 and 256 pixels. Conversion only resizes/packages the generated artwork and preserves its alpha channel.
- The executable embeds the ICO through `ApplicationIcon`. Avalonia loads the same icon for all app windows.

## Generation prompt

Use case: style-transfer / app icon. Input image is the user's Stream Avatar Studio icon, supplied as visual reference. Create its CLOCK/TIMER sibling icon for the ContentWatch desktop application. Preserve the family resemblance: chunky rounded silver/off-white device casing with thick nearly black border, soft silver gradients, restrained glossy highlight on upper left, front-facing orthographic view, cyan-to-electric-blue accents, tiny red and green secondary accents. Replace the avatar face/eyes and lower circuit decoration with ONE dominant beautifully simple analog clock: a dark circular inset clock face inside the silver rounded-square housing, four bold light cardinal tick marks (no numerals), two thick cyan and blue hands and a clear central pivot. The hands and clock face must remain unmistakable at 32px. A small silver stopwatch crown above the housing can reinforce the timer function. Keep secondary details minimal; a small red indicator and green square button near the lower edge are enough. Match the reference's friendly polished dimensional icon style, not photorealism. It must read as a clock rather than a robot face. Single finished icon only, centred on a square canvas with balanced 6–8% outer safety margin, entirely visible, genuine transparent alpha outside the device. No text, lettering, brand name, watermarks, checkerboard pattern, background tile, scene, detached elements or cast shadow outside the silhouette.
